# ТОО «ВЖДО» — дашборд исполнительской дисциплины

Интерактивный executive-dashboard по системному промпту v5.

## Что внутри

- Ровно 3 слота загрузки: `1.xlsx` (протоколы), `2.xlsx` (e-Өтініш), `3.xlsx` (входящие).
- `structure.xlsx` подхватывается автоматически из `public/structure.xlsx` (не показывается как операционный upload).
- Сроки пересчитываются от текущей календарной даты дашборда (`referenceDate`), колонки «Осталось дней» и «Осталось/просрочено дней» не используются.
- Завершённые статусы (`Снят с контроля`, `Завершено`, `Выполнен/Выполнено`) никогда не становятся просроченными.
- KPI кликабельны, таблица показывает ровно те же записи.
- Данные обрабатываются в браузере (SheetJS) и сохраняются в IndexedDB.

## Запуск

```bash
cd vzhdo-dashboard
npm install
npm run dev
```

Сборка для GitHub Pages / статики:

```bash
npm run build
npm run preview
```

`vite.config.ts` использует `base: './'`.

## Как пользоваться

1. Откройте пункт **Загрузка**.
2. Загрузите три выгрузки.
3. На **Обзоре** смотрите сводку и список «Что требует внимания».
4. На страницах модулей фильтруйте, кликайте KPI и открывайте карточку записи.

Игнорируемые колонки (дальнейший контроль, ИИН, корреспондент, готовые «осталось дней» и т.д.) в KPI и поиск не попадают.
